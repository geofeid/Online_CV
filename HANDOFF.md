Four repositories, one content file, four public surfaces.

| Repo | Live at | Deploys via | Role |
|---|---|---|---|
| **Online_CV** | `geofeid.github.io/Online_CV/` | GitHub Actions → Pages | Generator + **source of truth for all content** |
| **portfolio-v2** | `geofeid.github.io/portfolio/` | GitHub Actions → Pages | Angular portfolio, fetches content at runtime |
| **digiminds-next** | `www.digiminds.gr` | Vercel on push to `main` | Studio brand, lead-gen funnel |
| **OnlineCV** | `geofeid.github.io/OnlineCV/` | GitHub Actions → Pages | **Retired.** Stale since 18 Aug, download link 404s |

### The content pipeline

```
Online_CV/content.env             → online CV text
Online_CV/content.print.env       → print-only overrides (merged on top)
Online_CV/content.portfolio.json  → projects, timeline, 111 skills
        │
        │  npm run build:pdf
        ▼
Online_CV/dist/
        ├── index.html                   online CV
        ├── print.html                   A4 sheet
        ├── Georgios Feidakis CV.pdf     built by CI, never committed
        └── content.json                 { cv, portfolio }  ← consumed downstream
        │
        ├──────────────► portfolio-v2   fetches /Online_CV/content.json at runtime
        └──────────────► digiminds-next fetches it at build time (src/lib/work.ts)
```

**Edit content in `Online_CV` only.** A change there reaches every surface.
`content.json` is regenerated by CI; do not hand-edit `dist/`.

## 4. Hard-won constraints — do not rediscover these

### The printed CV holds exactly one A4 page

Measured against **real Poppins**, not guesses:

- The sidebar fits **12 skill rows**. Thirteen spills to a second page.
- A skill label wraps past roughly **20 uppercase characters**, and each wrap
  silently costs a row.
- The certifications column has about **50px of slack**; the left column is what
  usually drives page height.
- `content.limits.env` enforces per-field character caps at build time. The
  build fails loudly rather than producing two pages —
  `CERT6_DESC1 is 134 chars; max is 120` is a real failure you will hit.

### Fonts are self-hosted, and that is deliberate

The headless Chrome that renders the PDF **has no network**. A CDN font link
renders as Helvetica locally and as the real font in CI, so a sheet that
measures as one page on your machine comes back as two from the workflow. This
cost three debugging rounds before it was understood.

Both Poppins (`src/fonts/poppins-*.woff2`, latin subsets only) and Font Awesome
(`src/fonts/fa-*.woff2`, 13 glyphs declared in `_icons.scss`) now ship with the
repo. **The build reaches nothing outside itself.** Verify with:

```bash
python3 -c "
import re,glob
d=open(glob.glob('dist/*.pdf')[0],'rb').read()
print(len(re.findall(rb'/Type\s*/Page[^s]', d)), 'pages')
print(sorted(set(x.decode() for x in re.findall(rb'/BaseFont\s*/([A-Za-z0-9+\-,_]+)', d))))"
```

Expect **1 page** and five embedded faces: two Poppins, three Font Awesome.

### Online CV and print CV diverge on purpose

`content.print.env` overrides `content.env` for the sheet. Examples currently
live:

- Udemy titles carry course hours online (`(10.5 hrs)`), bare names in print.
- Workearly prints as one line, `Remote Summer School (28 days)`, with the other
  four certifications in its description. Online shows all five in full.

If a change appears online but not in the PDF, or vice versa, this file is why.

### Workearly is one programme, not five certifications

Confirmed from the Credly badge definitions: **Remote Summer School** is the
programme certificate. The other four are what it awards — three core (AI
Productivity Specialist, Communication & Influence, Remote Work Readiness) plus
one specialisation chosen from ten tracks, which was **Vibe Coder**. The issue
timestamps agree: the three core badges came the evening of 6 July, Vibe Coder
the next morning, and Remote Summer School four minutes after it.

The programme publishes **no per-certificate hours** — only 28 days at fifteen
minutes a day. Do not invent an hour count.

### Course lengths, researched

GitHub Actions 10.5h · Jenkins From Zero To Hero 10.5h · Docker & Kubernetes 23h.
These are the current Udemy listings, not necessarily what the certificates say.

## 5. digiminds-next — the i18n layout

Greek keeps the **bare URLs it already ranks for**; English sits under `/en`.

```
/            Greek    (middleware rewrites to /el internally, URL stays "/")
/el          308 → /  (never two addresses for one page)
/en          English
/work        /en/work
/work/<slug> /en/work/<slug>    11 projects × 2 locales = 22 pages
```

**Nothing auto-redirects on `Accept-Language`.** Googlebot crawls with English
headers; sending it away from the Greek home page would destroy the rankings
this layout exists to protect. Humans switch language from the navbar; search
engines read hreflang.

Copy lives in `src/i18n/dictionaries/{el,en}.ts` — 381 lines each, same shape,
so a missing English key is a compile error. The English is **written to the
same funnel, not translated**.

Case studies come from `content.json` at build time. Greek wording is an overlay
keyed by slug in `src/i18n/work/el.ts`; a project with no translation renders in
English rather than disappearing.

Featured on the home page: **Panousos Boats · Habitly · Mentorly**.

## 7. Voice and positioning rules

These were decided deliberately and reversed once already. Do not re-litigate.

- **Angular is the enterprise subject** everywhere. React and Next.js are the
  freelance stack. Recruiters are targeted for Angular front-end only.
- **AI is a capability, not an identity.** One line at most. The instruction was
  explicit: do not read as someone who builds with AI.
- Lead with the **problem solved and the human**, not the stack. Tech belongs in
  the experience descriptions, not the About.
- **Never publish client code.** Client work is described by industry, never by
  client name, except where the project is already public.
- **No under-development projects** in profile copy — Sovereign voice AI,
  Habitly and Mentorly are fine on the portfolio, not in the LinkedIn About.
- Profile skills come from his own master list, selected from the picker's
  "Currently in your Skills section" group — never typed as free text.

## 8. Debugging notes that will save time

**The preview pane does not composite.** `requestAnimationFrame` never fires
(`visibility: hidden`, 0 ticks in 1.5s), so any framer-motion animation stays
frozen at its `initial` value and content looks invisible. This is a harness
artefact, not a bug. Verify layout by setting the styles directly:

```js
document.querySelectorAll('[role="listitem"]').forEach(c => {
  c.style.opacity = '1'; c.style.transform = 'none'
})
```

**Portfolio screenshots live under `img/`.** `content.json` stores
`shots/name.png`; the portfolio serves them from
`geofeid.github.io/portfolio/img/shots/name.png`. Getting this wrong 404s every
image silently.

**Full Disk Access drops.** Twice in one session the filesystem became
unreadable — `Operation not permitted` on both Bash and file tools. Fixed by
granting Full Disk Access and restarting the app.
